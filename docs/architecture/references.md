# Reference Provenance

NikiCode architecture is informed by:

- **OpenAI Codex** (primary): runtime separation between engine and UI, event-driven execution, startup orchestration, MCP lifecycle, skills discovery, sandbox & permission architecture.
- **OpenCode** (secondary): Go client-server model with Bubble Tea TUI.
- **Kimi Code** (secondary): turn lifecycle and tool dispatch patterns.
- **Claude Code** (behavioral reference): permission tiers, approval prompts, session resume.

No source code from these projects is vendored into NikiCode.
