# NIKI Verifier Trust Model (docs/verifier/TRUST_MODEL.md)

Calibration of the completion-gate verifier against a seeded
suite of known-outcome cases. Generated by `internal/verifier`
calibration (V7); regenerate with the verifier test suite.

## Invariants (absolute)

- A clean passing suite **verifies**.
- A **tamper** case (test deleted around the run) is **never** verified.
- A **weakening** case (assertions removed / skips added) is **never** verified.
- An unknown stack is **inconclusive**, never a pass.
